# יומן תינוק — הוראות התקנה

## 1. העלאה לאינטרנט (GitHub Pages, חינם)
1. ב-github.com צרו מאגר חדש (Public), למשל `baby-log`.
2. Add file ← Upload files: העלו את כל הקבצים מהתיקייה (index.html, manifest.json, sw.js, icon-192.png, icon-512.png).
3. Settings ← Pages ← Branch: `main` ← Save.
4. אחרי דקה הכתובת תהיה: `https://<שם-המשתמש>.github.io/baby-log/`

## 2. התקנה בטלפון
פתחו את הכתובת ב-Chrome באנדרואיד ← תפריט ⋮ ← "הוספה למסך הבית" / "התקנת אפליקציה".

## 3. התקנת השרת וחיבור לדרייב (פעם אחת, כ-5 דקות)
השרת הוא Google Apps Script: רץ בחינם על השרתים של גוגל, בחשבון שלך, ושומר את הנתונים בדרייב שלך. לא צריך Google Cloud ולא Client ID.

1. היכנסו ל-script.google.com עם החשבון שבו תרצו לשמור את הנתונים ← "פרויקט חדש".
2. מחקו את מה שכתוב והדביקו את כל התוכן של `server/Code.gs`. שמרו.
3. ⚙️ Project Settings ← Time zone: `(GMT+02:00) Jerusalem`.
4. **Deploy ← New deployment** ← ⚙️ ליד Select type ← **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   ← Deploy ← אשרו הרשאות (Drive + מייל).
   אם מופיע "Google hasn't verified this app": Advanced ← Go to project. זה הסקריפט שלכם.
5. חזרו לעורך, בחרו בפונקציה `setup` למעלה ← **Run**.
6. יגיע אליכם מייל "שרת יומן התינוק פעיל" עם **כתובת השרת** ו**קוד גישה**.
7. באפליקציה: ⚙️ הגדרות ← חיבור לגוגל דרייב ← הדביקו את שניהם ← "חיבור ובדיקה".
   תופיע ההודעה "מחובר לדרייב של <החשבון שלכם>".

בן/בת הזוג: מתקינים את האפליקציה בטלפון שלהם ומזינים את אותה כתובת ואותו קוד, ורואים את אותם נתונים.

"Anyone" אומר שכל אחד יכול לפנות לכתובת, אבל בלי קוד הגישה השרת מסרב. אל תשתפו את הקוד.

אם תשנו בעתיד את Code.gs: Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy (הכתובת נשארת אותה כתובת).

מה השרת עושה:
- שומר וטוען את כל הנתונים מ-`baby-log.json` בדרייב, וממזג שינויים משני טלפונים בלי לדרוס.
- **כל 5 דקות** שולח מייל לתזכורות שסומן בהן "לשלוח גם מייל", ולהתראת "לא הייתה האכלה X שעות" (אם הופעלה בהגדרות).
- **כל לילה ב-03:00** שומר עותק מתוארך בתיקייה "Baby Log - גיבויים". העותקים לא נמחקים.

## איפה הנתונים נשמרים, ולכמה זמן
- **כל התיעודים נשמרים לתמיד.** האפליקציה לא מוחקת אף תיעוד בעצמה, ורשימת "כל התיעודים" מציגה את כולם מהיום הראשון.
- מסך הסיכום מציג שבוע, חודש או **הכול**.
- העותק הראשי: `baby-log.json` בדרייב. עותקי גיבוי יומיים בתיקייה נפרדת.
- גם במכשיר יש עותק, כך שהאפליקציה עובדת בלי אינטרנט ומסתנכרנת כשהחיבור חוזר.

## שימוש
- **הנקה / שינה / זמן בטן**: לחיצה אחת מתחילה טיימר, לחיצה שנייה מסיימת ורושמת.
- **פיפי / קקי / גם וגם**: לחיצה אחת ונרשם.
- **בקבוק**: בחרו כמות מהירה או הקלידו מ״ל ← הוספה.
- **תרופות**: שם + מינון; תרופות שהוזנו נשמרות לבחירה מהירה.
- **עריכה**: לחיצה על תיעוד ברשימה מאפשרת לשנות סוג, שעת התחלה וסיום, צד, כמות, תרופה ומינון, הערה, או למחוק.
- **שכחתם לתעד?** "הוספת תיעוד שנשכח" ברשימת התיעודים.
- אחרי כל תיעוד יש כפתור "ביטול" לכמה שניות.
